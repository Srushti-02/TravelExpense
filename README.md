# ExpenseFlow – Smart Expense Approval Portal

## Project Overview

ExpenseFlow is a role-based expense management application built using ASP.NET Core MVC and SQL Server.

## Modules

- User Registration
- User Login
- Employee Dashboard
- Expense Claim Submission
- Manager Approval/Rejection
- Finance Payment Processing
- Admin Dashboard

## Technologies Used

- C#
- ASP.NET Core MVC
- SQL Server
- Entity Framework Core
- LINQ
- Git
- GitHub
- Docker
- Azure DevOps
- Azure App Service

## Workflow

Employee → Create Claim

Manager → Approve / Reject

Finance → Mark Paid

Admin → Monitor Reports
